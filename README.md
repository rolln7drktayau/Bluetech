# BlueTech Innovation Website

Site statique premium généré pour BlueTech Innovation.

## Contenu
- 10 pages principales + une page Brand Guidelines
- CSS responsive complet
- JavaScript léger pour menu mobile et animations
- 5 concepts de logo en SVG et PNG
- Logo principal, versions noire/blanche, PNG transparent, favicon
- SEO, textes marketing, stratégie de lancement et wireframes dans `/docs`

## Pages
- index.html
- about.html
- services.html
- digital-transformation.html
- business-optimization.html
- transportation-logistics.html
- projects.html
- blog.html
- careers.html
- contact.html
- brand-guidelines.html

## Utilisation
Ouvrir `index.html` dans un navigateur ou publier le dossier sur un hébergement statique.

## Personnalisation rapide
- Modifier les couleurs dans `assets/css/styles.css` au niveau de `:root`
- Remplacer les coordonnées dans `contact.html`
- Connecter le formulaire à un CRM ou service email
- Remplacer le domaine dans `sitemap.xml`
